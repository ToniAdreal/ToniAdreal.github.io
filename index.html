verifygate

面向编码 Agent 的交付前验证工具：按任务规格在沙盒副本中运行单元测试、复现脚本与 lint / 类型检查；LLM 只提出补丁与解释，PASS/FAIL 只由确定性校验决定，并输出 hash 链签名、可重放的证据记录。Pre-delivery verification harness for coding agents: runs a task spec's unit tests, repro scripts and lint/type gates in a sandboxed copy; the LLM only proposes patches and explanations, deterministic checks decide PASS/FAIL, and a signed, hash-chained, replayable evidence record is produced.

PythonNVIDIA Nemotron (Nebius Token Factory)AI Agent

VerifyPay (verifypay-arc)

Arc 链上的 USDC 托管合约：仅当指定验证者对交付物哈希签署 EIP-712 PASS 时放款给 AI 编码 Agent，超时未通过则付款方退款；可与 verifygate 证据记录配合。使用 Arc Studio 构建。USDC escrow on Arc that pays an AI coding agent only when a designated verifier signs an EIP-712 PASS over the deliverable hash; the payer refunds if no PASS arrives by the deadline. Pairs with verifygate evidence records. Built with Arc Studio.

SolidityEIP-712USDCArc

escrow-state-machine-ts

确定性托管资金放行状态机（CREATED → FUNDED → MILESTONE_SUBMITTED → VERIFIED → RELEASED）与费用计算、gross-to-net 结算；审计历史 hash 链防篡改，生成签名结算 Webhook，含争议仲裁分支。Deterministic escrow fund-release state machine (CREATED → FUNDED → MILESTONE_SUBMITTED → VERIFIED → RELEASED) with fee calculation and gross-to-net settlement; hash-chained audit history, signed settlement webhooks, and a dispute/arbitration branch.

TypeScript零运行时依赖zero runtime deps

rfc9421-signing-demo

按 RFC 9421 实现 HTTP 消息签名与验签（ed25519 / hmac-sha256），RFC 9530 Content-Digest 消息体绑定、多方追加签名、nonce 防重放与 JWKS 密钥解析。演示项目，非认证实现。HTTP message signing and verification per RFC 9421 (ed25519 / hmac-sha256) with RFC 9530 Content-Digest body binding, multi-party signatures, nonce replay protection and JWKS key resolution. A demo, not a certified implementation.
